How to print to PDF

Open any variant, hit ⌘P (or Ctrl+P), choose Save as PDF, set margins to None and scale to 100%. Output is a clean 8.5 × 11 single page.

What to swap before printing

1. Replace assets/qr-placeholder.svg with your real QR PNG/SVG (keep the same filename and the layout stays put).
2. Confirm the council name in variant B (currently “Pacific Skyline”).
3. Tweak the family-pack quote — it's the same in all three variants and might want your own voice.

What changes globally

Edit shared/tokens.css to recolor the whole set at once (all variants pull from the same Sea Ranch palette).
